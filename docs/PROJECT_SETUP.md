# تشغيل البروجكت

## المستودع والمهام

أضف herosaud88-source/poet إلى بروجكت الشعر → Project settings → Environment.
اختر بيئة Cloud، ثم ابدأ مهمة جديدة لتقرأ الملفات المضافة. المهام القائمة قد تعمل من نسخة قديمة.
أبقِ hotel-system في بروجكت qroom.

محادثة البروجكت تنسق العمل؛ المهام السحابية تستنسخ المستودع وتقرأ CLAUDE.md والمهارات.
اختبر الأدوات في مهمة سحابية باستدعاء فعلي، لا من وصف المحادثة الأساسية لقدراتها.

## تعليمات مقترحة للبروجكت

اكتب الشعر حسب style/PROFILE.md والأمثلة المعتمدة. استخدم مهارة najdi-poetry.
اجعل عمل الشعر في مستودع poet. نفذ الأدوات وكتابة الملفات في مهمة سحابية،
واذكر ما تحقق تشغيله وما بقي إعدادًا. لا تستخدم فاحص الفصيح حكمًا نهائيًا على وزن النبطي.
ابدأ بالطلب المحدد، ولا تنشئ مهام إضافية دون حاجة.

## سوار

أُضيف إعداد HTTP في .mcp.json. وفق توثيق Claude، المهام في مشروع ذي مستودع واحد
تستطيع تحميل إعداد MCP من المستودع. ذلك لا يثبت أن الخادم متاح أو أن الأداة تعمل.

1. داخل مهمة جديدة اعرض حالة siwar عبر /mcp إن كان متاحًا، أو قائمة Connectors.
2. اطلب معنى «طمأنينة» من معجم الرياض؛ تحقق من استدعاء فعلي واسم الأداة والنتيجة.
3. إذا فشل الاتصال افحص سماح بيئة Cloud بالنطاق mcp.arai.center.
4. عند الحاجة أضف موصلًا مخصصًا من إعدادات Connectors بعنوان https://mcp.arai.center/mcp.
   تجنب إعداد نسختين إذا كانت الأولى تعمل. اتبع طلب الثقة أو التفويض إذا عرضته الواجهة.
5. اذكر العطل كما هو بدل الادعاء بأن الإعداد يعني اتصالًا ناجحًا.

## أدوات الفصيح الاختيارية

عند الحاجة إلى PyArud لتحليل فصيح فقط:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r tools/requirements-classical.txt
```

لم تثبت الحزمة ضمن تجهيز المستودع. arud-skill مهارة خارجية مبنية عليها؛ هي اختيارية
ومختلفة عن najdi-poetry الخاصة بذوق المستخدم. بقية الأدوات في tools/CATALOG.md.

## التحقق

- اقرأ CLAUDE.md وstyle/PROFILE.md و.claude/skills/najdi-poetry/SKILL.md.
- شغّل python3 tools/check_structure.py --help.
- اختبر سوار فعليًا واذكر إن تعذر.
- أضف أمثلة حقيقية قبل الحكم على جودة محاكاة الأسلوب.
