# القصائد المحفوظة

هذا المجلد مرجع قصايد saud. كل قصيدة جديدة يعتمدها تنضاف هنا بملف خاص، ويتحدث الفهرس.
لكل ملف: العنوان، الحالة (منشورة / معتمدة / مسودة / مثال)، الموقف، الذبّة، ثم الأبيات.
كل شطر بسطر، وسطر فارغ بين الأبيات. لا تصنّف المسودة معتمدة إلا إذا اعتمدها saud.

## فحص التنسيق

tools/check_structure.py يقرأ ملف txt. للفحص انسخ الأبيات إلى ملف مؤقت واستخدم:

```bash
python3 tools/check_structure.py poem.txt --format hemistichs --expected-bayts 3
```
