# الأدوات وحالة دمجها

تاريخ مراجعة التوثيق: 2026-10-19. هذه حالة الملفات المضافة، وليست شهادة اتصال حي.
الروابط وحدها لا تثبت البرامج، وقد تتغير الخدمات والإتاحة.

| الأداة | الدور | الحالة هنا وطريقة الدمج |
|---|---|---|
| najdi-poetry | تطبيق ذوق المستخدم في الكتابة والمراجعة | مهارة مضافة داخل .claude/skills، تُحمّل من المستودع في المهام الجديدة |
| Siwar — سوار | معاني ومترادفات وجذور | إعداد HTTP مضاف في .mcp.json؛ التشغيل الحي غير مختبر |
| check_structure.py | عدد الأبيات وتنسيق الأشطر والنهايات النصية | سكربت محلي مضاف ومختبر، بلا حزم خارجية؛ لا يفحص الوزن |
| PyArud | تحليل الوزن والقافية للفصيح | اعتماد اختياري محدد في requirements-classical.txt؛ غير مثبت |
| arud-skill | تعليمات وسكربتات عروض مبنية على PyArud | مرجع فقط؛ غير مثبت. المشروع يوثق تركيبًا لـClaude Code، ودعم النبطي غير متحقق منه |
| Qafiyah — قافية | بحث في الشعر والشعراء والبحور والقوافي | موقع + GitHub + API؛ مرجع فقط، لم يضف عميل أو موصل آلي هنا |
| Qawafi — قوافي | تحليل البحر والقافية والتفعيلات والتشكيل | مشروع GitHub؛ غير مثبت، يحتاج تشغيلًا وربطًا مخصصًا |
| Ashaar — أشعار | نماذج لتحليل الشعر وتوليده | مشروع بحثي/برمجي؛ غير مثبت |
| InstructPoet-AR | بيانات وكود للكتابة والمراجعة والإكمال، تشمل لهجات خليجية | غير مثبت؛ إعداد بحثي وتشغيل مستقل، وليس بلقن جاهزًا هنا |
| Notion | حفظ أمثلة وتصحيحات وقصائد | موصل في دليل Claude؛ لم يربط حساب من هذا المستودع |
| Google Drive | ملفات القصائد والمراجع | موصل Claude؛ لم يربط حساب من هذا المستودع |
| GitHub | حفظ ملفات النظام | هذا المستودع مصدر الملفات؛ يضاف إلى إعدادات البروجكت |
| Musajala — مساجلة | المشاركة وإكمال أبيات في منصة شعر عربي | غير مثبت؛ MCP بتركيب يدوي، لا وجود متجر متحقق منه |
| Poetry MCP / Elliot Plant | الوزن والقوافي الإنجليزية باستخدام CMU | مستبعد من الأساسيات؛ لا يخدم قصائد المستخدم النبطية |
| الديوان الشعبي | مصدر أمثلة شعر شعبي | رابط مرجعي؛ تعذر فتحه مباشرة أثناء البحث، ولا موصل متحقق منه هنا |
| وزن الشعر النبطي — الشعبي | تطبيق مستقل للطروق والأوزان | غير مجرب، آخر تحديث ظاهر 2017؛ تطبيق iOS لا موصل Claude متحقق منه |

## حدود النسخة

لا يوجد مدقق وزن نبطي مثبت ومتحقق منه. لا تعتمد فاحص الفصيح حكمًا على النبطي.
اختبر أي مرشح على أبيات نبطية صحيحة ومكسورة مع طريقة نطقها قبل اعتماده.
لا توجد أمثلة شعرية فعلية معتمدة في هذه النسخة.
