# poet — نظام كتابة الشعر النبطي

مساحة لكتابة القصائد بلهجة نجدية طبيعية وتطوير مرجع الأسلوب من الأمثلة والتصحيحات.
هذه النسخة تضيف تعليمات ومهارة وإعداد سوار وفاحص تنسيق محليًا.
القصايد المنشورة والمعتمدة محفوظة في poems/ وفهرسها poems/README.md. لا يوجد مدقق وزن نبطي متحقق منه.

## الملفات

| المسار | الاستخدام |
|---|---|
| CLAUDE.md | تعليمات Claude Code داخل المستودع |
| .claude/skills/najdi-poetry/SKILL.md | مهارة كتابة الشعر ومراجعته |
| style/PROFILE.md | قواعد الذوق الحالية |
| examples/approved/ | أمثلة يختارها المستخدم مع أسباب إعجابه |
| examples/rejected/ | أمثلة مرفوضة مع التصحيح |
| feedback/CORRECTIONS.md | سجل التصحيحات قبل وبعد |
| poems/ | مرجع القصايد المنشورة والمعتمدة والمسودات |
| .mcp.json | إعداد معجم سوار؛ نجاح الاتصال يحتاج اختبارًا |
| tools/ | فاحص التنسيق ودليل الأدوات الخارجية |

## الاستخدام في Claude

1. أضف herosaud88-source/poet إلى Project settings → Environment.
2. ابدأ مهمة سحابية جديدة بعد إضافة الملفات؛ المهمة القائمة قد تستخدم نسخة قديمة.
3. اطلب قراءة CLAUDE.md وstyle/PROFILE.md، ثم أعطِ الموقف المطلوب.
4. اطلب حفظ التصحيحات التي تريد تطبيقها لاحقًا.

تفاصيل التهيئة في docs/PROJECT_SETUP.md. حالة كل أداة في tools/CATALOG.md.
كتابة الرابط في الدليل لا تثبّت الأداة ولا تربط حسابًا خارجيًا.

## فحص تنسيق قصيدة

يتطلب Python 3.10 أو أحدث بلا حزم خارجية. اكتب كل بيت في سطر وشطريه مفصولين بـ #.

```bash
python3 tools/check_structure.py poem.txt --expected-bayts 3
```

للشطر في كل سطر استخدم --format hemistichs. النتيجة تصف العدد والتنسيق وتعرض
النهايات المكتوبة، ولا تثبت الوزن أو القافية المنطوقة أو طبيعية اللهجة.
